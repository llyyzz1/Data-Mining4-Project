# Adult 与 Mushroom 的跨数据集比较分析

## 1. 比较目的与数据差异

本研究选择 UCI Adult 和 Mushroom 两个二分类数据集，分别预测个人年收入是否超过 50K，以及蘑菇是否有毒。比较的研究问题是：在分类器参数和评估协议一致的条件下，模型表现如何随样本规模、属性类型、缺失情况和类别比例变化；一种数据集上的领先模型及预处理选择，能否在另一种数据集上保持优势。

**表 1　两个数据集的主要特征。特征数均不包含目标变量，类别比例和缺失比例以项目实际使用的全量数据为准。**

| 比较维度 | Adult | Mushroom |
| --- | --- | --- |
| 样本数 | 48,842 | 8,124 |
| 原始特征数 | 14 | 22；删除常量属性 `veil-type` 后为 21 |
| 属性类型 | 6 个数值属性、8 个分类属性 | 全部为分类属性 |
| 目标与正类定义 | 高收入 `>50K = 1` | 有毒 `poisonous = 1` |
| 正类样本 | 11,687，约 23.93% | 3,916，约 48.20% |
| 含至少一个缺失值的样本 | 3,620，约 7.41% | 2,480，约 30.53% |
| 统一基线的训练／测试样本数 | 39,073／9,769 | 6,499／1,625 |

两个数据集在样本量、属性类型、缺失比例和类别不平衡程度四个维度上均存在差异，符合课程要求的至少两个维度对比。Adult 的样本量约为 Mushroom 的六倍，但其高收入正类明显较少；Mushroom 的类别分布则接近平衡。Adult 含数值和分类属性，需要分别处理；Mushroom 的分类信息通过独热编码进入模型。两者缺失情况也不同：Mushroom 的缺失集中于 `stalk-root`，Adult 的缺失涉及工作类别、职业和出生国家等分类属性。因此，两者适合用于研究模型表现和预处理选择与数据特征之间的关系。[S1–S3]

## 2. 可复现的比较设计与预处理差异

统一基线固定使用 Adult 方案二作为参考，读取已保存的模型、预测和交叉验证均值，并核对模型参数及评估表；Mushroom 则采用相同分类器参数重新训练。两个数据集均按类别分层划分 80% 训练集和 20% 独立测试集，随机种子为 42。在训练集内执行十折分层交叉验证，设置 `shuffle=True, random_state=42`，报告验证准确率均值；随后在完整训练集上拟合模型，并在留出测试集上计算 Accuracy、Precision、Recall、F1、ROC-AUC 和 Kappa。填补、标准化和编码均在模型 Pipeline 内拟合，交叉验证时由每一折的训练部分学习所需参数。[S4–S5]

**表 2　统一基线的分类器设置。未列出的参数及软件版本保存在实验配置文件中。**

| 分类器 | 共同设置 |
| --- | --- |
| 决策树 | `max_depth=8, random_state=42` |
| 随机森林 | `n_estimators=200, random_state=42, n_jobs=-1` |
| 逻辑回归 | `C=1.0, solver="lbfgs", max_iter=1000, random_state=42`；当前版本默认 L2 正则化 |
| SVM | `kernel="rbf", C=1.0, gamma="scale", probability=True, random_state=42` |

预处理依据属性类型保留各自方案。Adult 方案二对数值属性使用中位数填补和标准化，对分类属性使用众数填补和独热编码。Mushroom 删除常量属性，并沿用原项目的数据读取和分类属性处理器。需要特别说明，Mushroom 建模文件中的缺失标记 `?` 被读取为普通字符串，因此虽然 Pipeline 包含众数填补器，实际填补器不会填补这些问号，问号最终作为一个类别被编码。30.53% 表示原始缺失比例，不能因建模输入没有 NaN 就将其写成“没有缺失”或“已完成众数填补”。[S1、S4、S6]

Mushroom 原有五折网格搜索及线性 SVM 的结果不纳入本次统一基线，以避免混用调参模型和固定参数模型。这里的 SVM 均为 RBF 核。统一参数指使用相同的分类器配置，并不表示两种数据得到相同的变换后特征空间；例如 `gamma="scale"` 的实际取值仍取决于输入数据。因此，本实验比较的是采用相同评估协议和分类器设置的两套完整流程，而非仅改变数据集、其他条件完全相同的因果实验。

图 1 显示，Mushroom 在四种分类器上的测试成绩均接近满分，而 Adult 的 Accuracy 约为 85%–86%，F1 仅约为 0.65–0.68。对相同分类器而言，两个数据集的表现差异明显大于 Adult 内部模型之间的准确率差异。这说明应结合任务和数据特征解释结果，不能仅依据样本量或算法复杂度预测表现。

### 3.1 Adult：领先模型取决于评价目标

在固定的方案二中，SVM 的测试 Accuracy 最高，为 86.01%；随机森林的 F1 和 Recall 最高，分别为 0.6774 和 63.05%；决策树的 Precision 和 ROC-AUC 最高，分别为 79.84% 和 0.9066。因此，Adult 上不存在对所有指标都占优的模型。

以决策树和随机森林为例，决策树漏判 1,067 名高收入者、误报 321 名低收入者；随机森林将漏判减少至 864 名，但误报增加至 540 名。随机森林在当前默认预测规则下更充分地识别正类，代价是更多误报，因而其 F1 更高而 Accuracy 略低。若研究目标强调识别高收入人群，Recall 和 F1 比单独的 Accuracy 更有解释价值；若误报代价较高，则需要同时考虑 Precision。该结论是当前测试结果的描述，不代表已通过测试集完成最终模型选择。

Adult 的多数类约占 76.07%，始终预测低收入就可在全量类别分布下取得约 76.07% 的准确率，却完全不能识别高收入者。虽然当前四种模型都超过这一参照，其正类 Recall 仍仅为 54.36%–63.05%。这解释了为什么 Accuracy 较高时仍可能遗漏大量正类。决策树较高的 AUC 与较低的 Recall 并不矛盾：AUC 衡量分数排序能力，而 Recall 取决于实际采用的预测规则。

### 3.2 Mushroom：高可分性与模型成绩的饱和

Mushroom 测试集包含 842 条可食用和 783 条有毒记录。决策树、随机森林和 SVM 均预测正确；逻辑回归将 1 条有毒记录误判为可食用，未将可食用记录误判为有毒，因此其 Precision 为 100%，Recall 为 99.87%。逻辑回归的 AUC 为 1.0000，表示当前测试集的概率排序完全区分了两类，并不表示默认预测规则下没有分类错误。[S7]

Mushroom 的接近满分结果与当前数据较强的类别可分性相符。描述性列联统计显示，`odor` 的九个类别中有八个在当前全量样本中仅对应一种目标类别；例如 `odor=f` 的 2,160 条记录全部为有毒。另一方面，`odor=n` 包含 3,408 条可食用和 120 条有毒记录，说明单一属性仍不能覆盖所有情况，需要结合其他属性。这一统计用于解释数据特征，没有用于额外筛选特征、调参或构造新模型，也不能替代独立测试。[S1]

独热编码后的分类属性组合可被树模型通过分支规则表达，也可被线性或核模型利用。逻辑回归接近满分，说明在当前编码和划分下，线性决策边界已能取得很高的分类效果；复杂模型的额外收益因此受到成绩上限的限制。结合列联统计，这些结果支持“当前 Mushroom 样本较易区分”的解释，但不证明所有真实蘑菇样本都具有相同规律。

### 3.3 跨数据集的模型排名为何不同

Adult 中，决策树的正类 F1 位于四种模型末位，而 Mushroom 中其 F1 与随机森林、SVM 并列最高。这说明深度为 8 的树在当前 Mushroom 样本中已足以表达有效的类别划分，但在 Adult 上仍存在较多高收入漏判。Adult 的混合属性、较强类别不平衡及当前模型未完全区分的正负样本，使 Accuracy 与正类识别能力之间的权衡更明显。该解释与观察一致，但本实验没有通过单独控制类别比例或特征类型来识别每个因素的独立贡献。

随机森林在 Adult 上的 F1 高于单棵树，表明当前配置下集成模型改善了正类识别；在 Mushroom 上，两者测试指标相同，无法观察到额外测试收益。SVM 在 Adult 上具有最高 Accuracy，但在 Mushroom 上与两个树模型并列，而非单独领先。因此，本次结果体现的是优势缩小、指标依赖和并列现象，并未出现所有指标都严格反转的模型排名，不能人为制造“一个数据集上获胜、另一个上失败”的结论。

![图 2　两个数据集训练集十折交叉验证的平均准确率](G:/GPTLEARNING/cross_dataset_comparison/outputs/cross_dataset_cv_accuracy.png)

图 2 表明，Mushroom 的高测试成绩也伴随 99.94%–100% 的训练集十折平均准确率；Adult 的对应均值为 85.09%–85.58%。因此，两个数据集的差异同时出现在本次交叉验证与留出评估中。CV 与测试成绩接近是结果一致性的证据，但不是没有过拟合或数据泄漏的证明。Mushroom 的单折结果也并非全部满分：决策树最低一折为 99.69%，逻辑回归和 SVM 最低一折为 99.38%，应避免把“平均接近满分”描述成“所有验证折都完全正确”。[S7]

## 4. 预处理选择的效果及其跨数据集适用范围

Adult 的三个方案分别采用删除含缺失属性记录、众数／中位数填补，以及保留分类缺失类别并配置数值缺失指示器等处理。至少三种预处理方法的目的在此可以区分：缺失处理用于保留可用于建模的记录，标准化用于协调数值特征尺度，独热编码用于避免给分类取值强加不存在的大小关系。[S6、S8]

为减少测试人群差异的干扰，表 4 重点比较使用相同训练／测试记录的方案二和方案三。

**表 4　Adult 预处理变化的模型依赖性。Accuracy 变化以百分点计算。**

| 模型 | 方案二 Accuracy | 方案三 Accuracy | Accuracy 变化 | 方案二 F1 | 方案三 F1 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 决策树 | 85.79% | 85.78% | −0.01 | 0.6468 | 0.6465 |
| 随机森林 | 85.63% | 85.53% | −0.10 | 0.6774 | 0.6742 |
| 逻辑回归 | 85.07% | 85.19% | +0.12 | 0.6557 | 0.6601 |
| SVM（RBF） | 86.01% | 86.22% | +0.21 | 0.6694 | 0.6747 |

保留分类缺失信息后，逻辑回归和 SVM 的 Accuracy、F1 均有小幅提高，随机森林和决策树则没有同步提高。因此，预处理效果与模型有关，不能宣称“保留缺失类别始终优于众数填补”。当前 Adult 的六个数值属性没有缺失，数值缺失指示器没有产生新增的有效信息，不能将改善归因于该指示器。方案一删除缺失记录后测试集减少至 9,039 条，与另外两方案的 9,769 条不同，因此涉及方案一的成绩比较同时受到测试人群变化影响，不能将全部差异解释为处理方法的净效果。[S8]

这些处理目的可推广，但具体选择需要适应数据。Mushroom 没有连续数值属性，因此不需要原样复制 Adult 的数值标准化分支；其缺失比例较高，删除全部缺失记录将使样本数从 8,124 降至 5,644，而保留 `?` 类别可以保留这些记录。当前 Mushroom 的高分说明该完整流程在现有评估中有效，并不能证明保留问号优于众数填补、删行或删除 `stalk-root`。原项目虽已导出这些备选数据版本，但尚未形成对应的模型性能对照，因此没有证据将 Adult 的预处理收益数值直接推广到 Mushroom。课程要求的预处理对比由 Adult 实验提供，Mushroom 的策略对比仍属于可进一步开展的实验。[S1、S6]

## 5. Apriori 结果的跨数据集解释

两个数据集均包含 Apriori 关联分析，用于补充分类结果的模式解释。Adult 使用最小支持度 0.05、最小置信度 0.60、最大项集长度 3，得到 1,886 个频繁项集、1,864 条规则，其中 208 条以收入为后件。Mushroom 的正式设置为最小支持度 0.30、最小置信度 0.80、最大项集长度 4，得到 888 个频繁项集、1,868 条规则，其中 106 条以类别为后件。[S9–S10]

Adult 的规则示例为：

> `marital-status=Married-civ-spouse, occupation=Exec-managerial → income=>50K`

其支持度约为 5.02%，置信度为 68.08%，提升度约为 2.85。即约 5.02% 的全体样本同时满足前件和高收入后件；在满足前件的样本中，约 68.08% 为高收入者，约为总体高收入比例的 2.85 倍。这是关联关系，不能解释为婚姻状态或职业导致收入变化。

Mushroom 的规则示例为：

> `bruises=f, gill-attachment=f, population=v → class=p`

其支持度约为 30.82%，置信度为 95.43%，提升度约为 1.98。该规则在当前数据中覆盖较多记录，且前件出现时有毒类别的比例明显高于总体的 48.20%。但 95.43% 的规则置信度仍不是零错误保证，不能单独作为实际食用安全判断依据。

这两个例子说明，Adult 的规则可用于描述特定人口与职业组合的收入关联，而 Mushroom 的规则可描述形态属性组合与毒性类别之间的关联。不过，由于支持度、置信度、项集长度和属性表示不同，不能根据“1,864 条与 1,868 条接近”推断两个数据集同样复杂，也不能仅凭规则数比较算法优劣。提升度还受到后件基准比例影响，Adult 的提升度更高也不等于规则预测更准确。规则数、支持度、置信度和提升度需要同时解释。

Mushroom 的支持度敏感性实验进一步显示，在置信度固定为 0.80 时，最小支持度由 0.50 降至 0.20，规则数从 119 增至 8,669，类别后件规则从 0 增至 547。这表明放宽支持度可发现较少见的模式，但会增加筛选和解释负担；该实验变化的是支持度，不能写成已同时检验了置信度变化的影响。两边规则均属于全量数据上的探索性发现，尚未报告独立测试集上的规则覆盖和可靠性，不能与表 3 的留出分类指标混为一谈。[S9–S10]

## 6. 有效性限制与研究启示

第一，虽然分类器参数和评估协议统一，预处理与数据属性仍不同，当前实验不能分离样本规模、类别不平衡、缺失处理和属性类型的独立作用。Mushroom 样本更少却得到更高成绩，说明“大样本必然取得更高分”不成立，但不构成减少训练数据有益的证据。

第二，结果来自一次固定种子的留出划分及训练集内十折验证。Mushroom 中仅一条记录的分类差异，以及 Adult 中较小的模型或方案差异，尚未通过重复划分或统计检验确认，不应宣称存在统计显著优势。Adult 方案二保存的 CV 结果仅包含均值，因此本节没有报告无法恢复的单折标准差或置信区间。

第三，Adult 原始数据存在重复记录跨训练／测试集合重叠的风险，当前比较沿用原流程，尚未通过去重或分组划分实验排除此影响。预处理置于 Pipeline 内可以控制折内拟合边界，但不能自动消除重复记录带来的有效性风险。

第四，Mushroom 当前测试集上的满分不保证对新地区、新物种、未见属性组合或有观测误差的数据仍然有效。尤其是将有毒样本误判为可食用具有较高实际代价，后续应优先检查有毒类 Recall、漏判数量和外部验证，而非仅追求总体 Accuracy。Adult 则应在明确误报／漏判代价后，使用训练阶段的验证结果研究类别权重或预测阈值，测试集用于最终评估，不应反复用于调参。

本研究表明，同一组分类器在不同数据上不一定保持相同优势。Adult 中需要同时权衡准确率、正类识别和概率排序；Mushroom 中多种模型已接近当前数据划分的成绩上限，模型复杂度增加未带来普遍可见的测试收益。可复用的是包含缺失处理、编码、折内拟合和多指标评估的流程原则，而具体预处理和模型选择仍需结合数据特征与任务代价验证。
